# PageResolver (Deprecated)

This repository is no longer maintained.

The PageResolver library has been renamed, superseded, and fully replaced by:

## Plugin.Maui.SmartNavigation

Migration/upgrade is simple, but there are a couple of breaking changes.

See the migration guide: [New repository](ttps://github.com/matt-goldman/Plugin.Maui.SmartNavigation)

New NuGet package: `Plugin.Maui.SmartNavigation`

SmartNavigation is the direct continuation of this project.

It includes:

* A cleaner API surface
* Stronger DI integration
* Type-safe Shell routing
* Improved lifecycle behaviour
* A new source generator
* Updated naming aligned with .NET conventions
* Full support for .NET 10

This repository is kept as a historical reference only and will not receive updates, fixes, or releases.

All future development takes place in the SmartNavigation repository.
